title: Timeline exports
description: Export Session Timelines or deliver signed events to your own endpoint.
---

Every Session has a versioned Timeline that can be downloaded as JSON from its detail page.
The export uses the logging level captured when that Session was requested.

## Event Sinks

Workspace administrators can configure one public HTTPS endpoint in **Settings**. Odyshell sends
each retained Timeline event in a signed `ods.timeline.v1` envelope.

Choose a detail level:

- **Privacy-minimal** contains lifecycle, identity and scope metadata.
- **Operational** can add automatically redacted operation metadata such as paths.
- **Diagnostic** can add raw non-command operation metadata and may contain secrets.

Event Sink detail is configured independently from the Workspace Timeline level. Event Sinks never
export command text, stdout, stderr, environment values or standard input at any detail level.
Diagnostic metadata can still contain sensitive values. Enable it only for an endpoint and
retention policy you trust.

Each request includes:

```text
X-Odyshell-Delivery: <unique delivery ID>
X-Odyshell-Timestamp: <ISO 8601 timestamp>
X-Odyshell-Signature: v1=<HMAC-SHA256 hex digest>
```

Calculate HMAC-SHA256 over the exact request body with the configured signing secret. Reject an
invalid signature, an old timestamp or a delivery ID already processed.

Failed requests use bounded exponential backoff. Recent delivery status and terminal failures are
available through the Server API. Odyshell does not follow redirects, and endpoints must resolve
only to public addresses.
