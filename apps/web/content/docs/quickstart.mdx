---
title: Quickstart
description: Connect a private Linux machine and run an approved Agent task.
---

This is the shortest Cloud workflow. It uses Linux for the persistent Client service.

## 1. Install `ods`

Install the CLI with Node.js 24 or newer:

```npm
npm install --global @odyshell/cli
```

## 2. Authorize the administrator CLI

```bash
ods login
```

Open the URL printed by the CLI and approve the request. The short-lived device code is already
embedded in the URL.

## 3. Connect a machine

In Odyshell Cloud, open **Machines**, select **Add**, and choose the capabilities the Client may
expose. Run the generated `ods up` command on the target machine. Relative host paths start from
the Home directory of the operating-system user running the Client; exact absolute paths can be
requested and reviewed separately.

The enrollment token in that command expires after ten minutes and works once. The Client then
keeps an outbound connection to Odyshell; the machine does not expose an inbound port. Do not run
`ods login` on the target: the signed-in Workspace member authorized it by generating the
single-use enrollment command.

## 4. Connect an Agent

In the Agent environment, register its persistent identity:

```bash
ods agent login "My Agent"
```

Open the displayed URL and approve the registration. This returns an expiring Agent Credential
that can request Sessions, but cannot execute an Operation by itself.

## 5. Run an approved Operation

Request a narrowly scoped Session by running:

```bash
ods machines
ods ping my-machine
ods exec my-machine -- uname -a
```

Open the Session approval URL printed by `ods exec`, review its machine, capability and typed
restriction, then approve it. A successful ping returns `Pong! 🏓`.

The CLI claims the approved Session, executes the Operation, and closes the Session. Cancelling
the Session or revoking its credential immediately prevents reuse.
