---
title: TypeScript SDK
description: Request typed Odyshell operations from a TypeScript agent.
---

Install the programmatic interface:

```npm
npm install @odyshell/sdk
```

```ts
import { Odyshell } from "@odyshell/sdk";

const ods = new Odyshell({
  serverUrl: process.env.ODYSHELL_SERVER_URL!,
  agentToken: process.env.ODYSHELL_AGENT_TOKEN!,
});

const agent = ods.agent({ id: agentId, name: "Dependency auditor" })
const request = await agent.requestOperationSession({
  machineId,
  purpose: "Inspect repository state",
  durationSeconds: 900,
  action: {
    kind: "process.exec",
    program: "git",
    args: ["status", "--short"],
    cwd: ".",
    env: {},
  },
});
```

After approval, call `agent.claim(request.id)` once. Pass the result to
`ods.claimedSession(claim).execute(machineId, action)`. Human, Agent and Session clients expose
different authority; an Agent Credential cannot execute an Operation.

Use environment variables or a secret manager for credentials. Never put an agent credential in
source code, logs, or generated documentation.

The shared operation contract covers typed process, filesystem and Docker log work. The operation
determines its capability and minimum restriction automatically. Authorization remains enforced by
the Server and target Client; TypeScript types are not a security boundary.

An Independent Agent can create Managed Agent identities after an administrator approves its
Delegation Policy:

```ts
await ods.proposeAgentPolicy({
  kind: "delegation",
  scopes,
  maxSessionSeconds: 600,
  maxManagedAgents: 3,
  validForSeconds: 30 * 24 * 60 * 60,
})

const child = await ods.createManagedAgent({
  name: "Dependency updater",
  scopes,
  maxSessionSeconds: 600,
  validForSeconds: 24 * 60 * 60,
})
```

Use `managedAgents()`, `disableManagedAgent(id)`, and `deleteManagedAgent(id)` for its lifecycle.
The Managed Agent receives no Agent Credential; the parent requests and claims Sessions for it.
