Use Odyshell to connect machines, create scoped agent credentials, and run typed operations. A
lightweight Client on each machine maintains an authenticated outbound connection to the
Odyshell Server.

## Choose a path

- **Administrators:** start with the [quickstart](/docs/quickstart), then learn how to
  [connect machines](/docs/machines) and [grant agent access](/docs/agents).
- **Agents:** use the local [MCP server](/docs/mcp), the [TypeScript SDK](/docs/sdk), or the
  [`ods` CLI](/docs/cli).

## Available operations

- Linux, macOS, and Windows Clients
- Structured process execution and explicit shell execution
- Typed filesystem operations
- Docker container logs
- Temporary sessions and agent credentials
- Privacy-minimal Control Events

Continue with the [quickstart](/docs/quickstart) to connect your first machine.
