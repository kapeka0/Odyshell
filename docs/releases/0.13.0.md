# Odyshell 0.13.0

Odyshell 0.13.0 adds dedicated local Client Profile management.

- `ods profiles ls` lists every valid local Profile with its machine, Server, and background state.
- `ods profiles status <name>` inspects one Profile.
- `ods profiles remove <name>` stops and deletes one local Profile without deleting its Cloud
  machine record.
- Profile output never exposes the Client private key, including when `--json` is used.

Install the release and restart each connected Client Profile:

| Package manager | Command |
| --- | --- |
| pnpm | `pnpm add --global @odyshell/cli@0.13.0` |
| npm | `npm install --global @odyshell/cli@0.13.0` |
| Yarn | `yarn global add @odyshell/cli@0.13.0` |
| Bun | `bun add --global @odyshell/cli@0.13.0` |

```bash
ods down --profile <name>
ods up --profile <name>
```
