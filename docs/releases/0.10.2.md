# Odyshell 0.10.2

Odyshell 0.10.2 makes remote MCP Sessions easier to resume and safer to plan.

- Machine discovery reports the host platform, architecture, runner and local capabilities.
- Runtime output is allowlisted and does not expose workspace paths or Client configuration.
- Agents can recover a recent Session Request when an MCP response is interrupted.
- MCP instructions tell agents to inspect the machine before choosing platform-specific commands.

Update the CLI and restart each connected Client:

| Package manager | Command |
| --- | --- |
| pnpm | `pnpm add --global @odyshell/cli@0.10.2` |
| npm | `npm install --global @odyshell/cli@0.10.2` |
| Yarn | `yarn global add @odyshell/cli@0.10.2` |
| Bun | `bun add --global @odyshell/cli@0.10.2` |
