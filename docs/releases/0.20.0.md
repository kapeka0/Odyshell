# Odyshell 0.20.0

Odyshell is now a free, Apache-2.0, self-hosted product distributed through Docker Compose. The
managed Cloud and paid-plan direction have been removed so the project can focus on community value
and sovereign agent access.

## Changed

- `ods` now connects to `http://localhost:4100` by default. Remote self-hosted installations must
  be selected explicitly with `--server`.
- Vercel runs in public-site mode automatically, serving only the landing and documentation while
  returning 404 for authentication, dashboard, OAuth, API, and unknown future routes.
- Every installation owns one sovereign Organization with no commercial limits on members,
  Machines, or Agents.
- The landing and product documentation now lead with Docker self-hosting and the community model.
- The complete Compose stack has been restored and verified on a Raspberry Pi 5 (`linux/arm64`),
  including an authenticated outbound Machine on the same installation.

## Removed

- Stripe checkout, customer portal, webhook handling, SDK dependency, secrets, and billing tests.
- Free, Pro, and Enterprise plans and all Machine or Agent entitlement enforcement.
- The managed Cloud deployment mode, hosted Server fallback, and Cloud-specific internal naming.
- Obsolete PostgreSQL plan and Stripe fields from the active Server data model. Existing unused
  columns remain untouched so operators can archive or remove them on their own schedule.

## Security

- Machine Local Policy, Session and Command bounds, rate limits, OAuth authorization, single-use
  enrollment, revocation, and audit retention remain enforced independently of commercial limits.
- Public-site mode fails closed for every private product and identity route.

Install `@odyshell/cli@0.20.0` or deploy the complete stack from the `v0.20.0` Docker sources.
