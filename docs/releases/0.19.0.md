# Odyshell 0.19.0

Odyshell 0.19.0 restores temporary Session authority, Human approval, and attributable command
timelines across the managed control plane.

## Added

- The Overview canvas shows live Agent-to-Session-to-Machine activity.
- Standard Agents request Human-approved Sessions; Operator Agents may start Sessions without a
  new approval while remaining bounded by Machine Local Policy.
- Session detail pages retain command output and lifecycle evidence in an attributable timeline.
- The CLI supports browser OAuth and the same Machine, Agent, Session, and Command operations as
  the web app.
- Machine Clients support Linux, macOS, and Windows background services.
- Managed Cloud plans include Free and Pro at USD 30 per member per month.

## Changed

- Task and Autonomy Policy are replaced by Session and Agent Role throughout protocol version 5.
- Client Profiles now carry `sessionProfile` and Session-named Local Policy limits. The obsolete
  Task-shaped configuration is intentionally rejected.
- Command output retention defaults to 30 days and remains configurable by the Organization host.

## Upgrade

Install `@odyshell/cli@0.19.0`. This minor release is intentionally incompatible with the
Task-shaped 0.18.0 Client configuration. Re-enroll an existing Machine from the dashboard, or use
an Organization-approved one-time operator repair that renames the Profile authority fields while
preserving the Machine identity.
