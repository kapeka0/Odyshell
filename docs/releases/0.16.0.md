# Odyshell 0.16.0

Odyshell 0.16.0 is the incompatible Task-native cutover. Agents are now the primary operators:
they use OAuth HTTP or remote OAuth MCP to request one-Machine Tasks and execute asynchronous shell
Commands. Humans use the dashboard for setup, optional approval, revocation, and audit.

- Task and Command replace Session and typed Operation across HTTP, MCP, WebSocket, Client state,
  PostgreSQL, dashboard, and documentation. Legacy routes, wire messages, SDK, local MCP, Docker and
  filesystem action profiles, delegation, Event Sinks, and compatibility migrations were removed.
- Every Machine publishes one required Task Profile and enforces its signed Local Policy outside the
  Agent. Command input is an exact shell command plus bounded timeout, output budget, and optional
  absolute working directory; caller environment and stdin are not accepted.
- Command output is sequenced, bounded, reconnectable, and audited with the exact command and
  execution metadata. Cancellation terminates the process tree and suppresses late results.
- Agent access uses OAuth installations scoped to one Organization. Revocation closes active Tasks,
  and remote MCP exposes only the Task/Command tools.
- Better Auth owns Human identity and Organization membership in PostgreSQL. Cloud supports isolated
  Organizations; the same distribution defaults to one sovereign self-hosted Organization without
  hosted plan limits.
- Machine enrollment remains delegated and single-use: an authenticated Human generates a
  short-lived command, while the Linux target runs `ods up --token ...` without a Human CLI login.

Install the release:

| Package manager | Command |
| --- | --- |
| pnpm | `pnpm add --global @odyshell/cli@0.16.0` |
| npm | `npm install --global @odyshell/cli@0.16.0` |
| Yarn | `yarn global add @odyshell/cli@0.16.0` |
| Bun | `bun add --global @odyshell/cli@0.16.0` |

Protocol v4 is intentionally incompatible with protocol v3. Upgrade Server, Web, CLI, and Client
together; there is no compatibility mode or migration adapter for the former authority model.
