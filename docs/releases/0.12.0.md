# Odyshell 0.12.0

Odyshell 0.12.0 makes persistent Agents and temporary Sessions the primary workflow.

- Session requests use a required short title, optional purpose, immutable machine scopes, and a
  maximum 24-hour duration.
- The dashboard can create a Session for an Agent, lists its machine, and shows a live verified
  Timeline with conservatively redacted process command shapes and exit status. Filesystem paths,
  search queries, Docker container names, and Operation output are not retained there.
- Remote and local MCP recover active Sessions through `sessions_list` and report machine platform,
  architecture, runner, capabilities, and default shell.
- `process.shell` supports dependent multi-command work while remaining temporary, explicitly
  approved, locally bounded, and audited command by command.
- Private member notifications cover approvals, Session lifecycle, machine enrollment, sustained
  outages, and Agent removal without recording Operation output.
- Opening targets fail closed when the Client does not acknowledge them within 60 seconds and can
  retry if that Client reconnects before the Session expires.
- Transport loss terminates local Operations before reconnecting and Server connection lifecycle
  updates are serialized per machine.

This release uses Client protocol 2. Update the CLI and restart every connected Client:

| Package manager | Command |
| --- | --- |
| pnpm | `pnpm add --global @odyshell/cli@0.12.0` |
| npm | `npm install --global @odyshell/cli@0.12.0` |
| Yarn | `yarn global add @odyshell/cli@0.12.0` |
| Bun | `bun add --global @odyshell/cli@0.12.0` |
