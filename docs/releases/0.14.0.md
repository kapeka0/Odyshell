# Odyshell 0.14.0

Odyshell 0.14.0 adds explicit, per-Profile sudo access for Linux Clients.

- Sudo remains blocked by default.
- `ods profiles configure <name> --allow-sudo` enables it only when passwordless sudo already works.
- `ods profiles configure <name> --deny-sudo` restores the default restriction.
- Machine details, approvals and MCP discovery disclose when root access may be possible.
- Text areas follow the application layout without browser resize handles.

Install the release:

| Package manager | Command |
| --- | --- |
| pnpm | `pnpm add --global @odyshell/cli@0.14.0` |
| npm | `npm install --global @odyshell/cli@0.14.0` |
| Yarn | `yarn global add @odyshell/cli@0.14.0` |
| Bun | `bun add --global @odyshell/cli@0.14.0` |

To allow passwordless sudo for one Linux Profile:

```bash
ods profiles configure <name> --allow-sudo
```

Use a narrow `NOPASSWD` sudoers policy. Odyshell never stores or submits a sudo password.
