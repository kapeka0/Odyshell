# Odyshell 0.13.1

Odyshell 0.13.1 fixes Profile service detection for pnpm installations on Windows.

- `ods profiles ls` now recognizes that the pnpm shim and package-store path refer to the same
  installed Client.
- A current background Client is no longer incorrectly shown as requiring a restart.

Install the release and restart each connected Client Profile:

| Package manager | Command |
| --- | --- |
| pnpm | `pnpm add --global @odyshell/cli@0.13.1` |
| npm | `npm install --global @odyshell/cli@0.13.1` |
| Yarn | `yarn global add @odyshell/cli@0.13.1` |
| Bun | `bun add --global @odyshell/cli@0.13.1` |

```bash
ods down --profile <name>
ods up --profile <name>
```
