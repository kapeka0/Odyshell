# Odyshell 0.10.1

Odyshell 0.10.1 completes the remote Session flow for agent clients.

- Session Requests appear in the dashboard before they are claimed.
- The MCP waits for the machine Client to acknowledge a Session before reporting it ready.
- Host profiles support exact absolute filesystem paths with local scope enforcement.
- Active Session nodes show the remaining access time.

Update the CLI and restart each connected Client:

| Package manager | Command |
| --- | --- |
| pnpm | `pnpm add --global @odyshell/cli@0.10.1` |
| npm | `npm install --global @odyshell/cli@0.10.1` |
| Yarn | `yarn global add @odyshell/cli@0.10.1` |
| Bun | `bun add --global @odyshell/cli@0.10.1` |
