# Odyshell 0.15.1

Odyshell 0.15.1 fixes MCP Session Requests that were rejected with a generic `Invalid input`
error when an agent omitted the short approval title.

- `session_request` now accepts both exact-operation and Host Shell requests without `title`.
- When omitted, Odyshell uses `purpose` as the short title or derives one from the requested
  authority. Approval, authorization and audit records still receive a bounded, non-empty title.
- Existing explicit titles, exact typed scopes, manual Host Shell approval and all denial rules are
  unchanged.

Install the release:

| Package manager | Command |
| --- | --- |
| pnpm | `pnpm add --global @odyshell/cli@0.15.1` |
| npm | `npm install --global @odyshell/cli@0.15.1` |
| Yarn | `yarn global add @odyshell/cli@0.15.1` |
| Bun | `bun add --global @odyshell/cli@0.15.1` |
