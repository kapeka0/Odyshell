# Odyshell 0.10.0

Odyshell 0.10.0 adds explicit local identity cleanup.

## Added

- `ods client remove --profile <name>` stops and deletes one local Client Profile.
- `ods reset --yes` signs out and deletes all named and legacy Client Profiles on the host.
- Both operations remove services before credentials and fail closed if service cleanup fails.
- Cloud machine records are never deleted implicitly by local cleanup.

## Install

| Package manager | Command |
| --- | --- |
| pnpm | `pnpm add --global @odyshell/cli@0.10.0` |
| npm | `npm install --global @odyshell/cli@0.10.0` |
| Yarn | `yarn global add @odyshell/cli@0.10.0` |
| Bun | `bun add --global @odyshell/cli@0.10.0` |
