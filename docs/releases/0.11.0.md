# Odyshell 0.11.0

Odyshell 0.11.0 makes machine access easier to recover and Agent Sessions easier to follow.

- `ods up` uses the current directory by default; relative and exact absolute host paths can be
  approved without configuring a machine workspace folder.
- A local Client Profile can replace an identity that was removed from the Server while refusing
  to replace an active identity.
- Workspace administrators can remove persistent Agent identities and revoke their active access.
- The dashboard delivers private, member-targeted notifications for Session approvals and machine
  enrollment.
- MCP request and status results tell agents exactly how to continue after human approval.
- Expected rejected Session targets retain their useful error instead of becoming an unrelated
  authentication failure.
- Absolute write paths and process working directories reject symlink escapes on the Client.

Update the CLI and restart each connected Client:

| Package manager | Command |
| --- | --- |
| pnpm | `pnpm add --global @odyshell/cli@0.11.0` |
| npm | `npm install --global @odyshell/cli@0.11.0` |
| Yarn | `yarn global add @odyshell/cli@0.11.0` |
| Bun | `bun add --global @odyshell/cli@0.11.0` |
