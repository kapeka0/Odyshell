# Odyshell 0.9.1

Odyshell 0.9.1 fixes persistent Client execution on Windows.

## Fixed

- Windows Client Profiles run through a hidden Task Scheduler launcher, so closing a terminal no
  longer disconnects the machine.
- `ods up` detects and replaces tasks created by an older CLI while preserving the enrolled Client
  identity and local policy.
- `ods client update` refreshes the platform service definition after installing a compatible
  release.

## Install

| Package manager | Command |
| --- | --- |
| pnpm | `pnpm add --global @odyshell/cli@0.9.1` |
| npm | `npm install --global @odyshell/cli@0.9.1` |
| Yarn | `yarn global add @odyshell/cli@0.9.1` |
| Bun | `bun add --global @odyshell/cli@0.9.1` |

Run `ods up` once for each existing Client Profile to replace an older Windows task.
