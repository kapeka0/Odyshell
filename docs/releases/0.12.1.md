# Odyshell 0.12.1

Odyshell 0.12.1 routes new Cloud CLI and Client configuration through the stable Odyshell Server
domain.

- Odyshell Cloud now defaults to `https://server.odyshell.com`.
- Existing Client Profiles using the Railway hostname remain valid and continue to reach the same
  Server.
- The health endpoint reports the active Client protocol version.

Update the CLI and restart each connected Client Profile:

| Package manager | Command |
| --- | --- |
| pnpm | `pnpm add --global @odyshell/cli@0.12.1` |
| npm | `npm install --global @odyshell/cli@0.12.1` |
| Yarn | `yarn global add @odyshell/cli@0.12.1` |
| Bun | `bun add --global @odyshell/cli@0.12.1` |
