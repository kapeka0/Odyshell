# Odyshell 0.18.0

Odyshell 0.18.0 removes the permanent Agent binding from Machine enrollment.

## Changed

- A Machine now belongs only to its Organization. `ods up` and **Add Machine** no longer accept or
  display an Agent.
- Local Policy remains the Machine owner's resource ceiling for Organization, duration,
  concurrency, timeout, output, and remote approval. It no longer contains Agent identities.
- Organization-bound Agents can discover Organization Machines, but discovery grants no execution
  authority.
- Agent-to-Machine authority exists only inside an expiring Task authorized by Autonomy Policy or
  optional Human supervision.
- The Client protocol advances to version 5. Older Clients fail closed and must be upgraded and
  re-enrolled because obsolete Local Policy configurations are intentionally rejected.

## Upgrade

Install `@odyshell/cli@0.18.0`, remove the old local Client Profile, and enroll the Machine again
using the Agent-free command generated by **Add Machine**.
