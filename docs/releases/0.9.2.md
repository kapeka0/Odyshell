# Odyshell 0.9.2

Odyshell 0.9.2 makes background Client startup reliable and connectivity-aware.

## Fixed

- Windows Client Profiles use a native no-console launcher supervised by Task Scheduler. Closing
  the terminal used to run `ods up` no longer stops the Client.
- Stopping the Windows task also stops its Node.js child process.
- `ods up` verifies the Server health endpoint before reporting that the Client is running, with a
  clear error for DNS, network, timeout, and unhealthy Server failures.
- Existing Windows Profiles replace older PowerShell and direct-Node task actions on their next
  `ods up`.

## Install

| Package manager | Command |
| --- | --- |
| pnpm | `pnpm add --global @odyshell/cli@0.9.2` |
| npm | `npm install --global @odyshell/cli@0.9.2` |
| Yarn | `yarn global add @odyshell/cli@0.9.2` |
| Bun | `bun add --global @odyshell/cli@0.9.2` |

Run `ods up` once for each existing Windows Client Profile to replace its previous task action.
