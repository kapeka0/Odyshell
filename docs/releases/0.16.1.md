# Odyshell 0.16.1

Odyshell 0.16.1 hardens the OAuth resource boundary introduced by the Task-native `0.16` release.

## Security

- Agent access tokens can target only the canonical Odyshell MCP resource. This applies the
  upstream workaround for `GHSA-p2fr-6hmx-4528` while the stable Better Auth `1.6` line remains in
  use; a client cannot switch between multiple allow-listed audiences at the token or refresh
  endpoint.
- The Server continues to require the exact canonical MCP audience, the `odyshell:agent` scope,
  an Organization claim, and a live non-revoked Agent installation.
- The coordinated lockfile pins `nanoid` to patched version `3.3.17`.

## Operations

- Cloud identity migrations run as an explicit idempotent deployment command instead of from
  serverless cold starts. Self-hosted Web still migrates before accepting traffic.
- The release workflow keeps its synthetic database URL scoped to Web build and documentation
  smoke steps, while PostgreSQL integration tests run only inside their isolated E2E database.

## Install

```bash
npm install --global @odyshell/cli@0.16.1
```
